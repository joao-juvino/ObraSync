# Capturas reais da demonstração

Os PNGs ainda não foram capturados. Depois de iniciar a aplicação:

1. `login.png`: `/obrasync/login.xhtml`, antes de autenticar, sem senha visível.
2. `dashboard.png`: topo de `/obrasync/vistorias.xhtml`, mostrando os indicadores com os dados demonstrativos.
3. `vistorias.png`: tabela da mesma página, com filtros, status e ações visíveis.
4. `evidencias.png`: botão de imagens de uma vistoria, após upload de uma fotografia de teste; mostrar galeria e controle de envio.
5. `laudo.png`: abrir o PDF baixado pelo botão de laudo; capturar a identificação e/ou página de evidências.

Não utilizar fotos com dados pessoais, credenciais ou informações de obras reais sem autorização.
